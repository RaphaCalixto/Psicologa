# Landing Page - Psicóloga Vera Miranda

Landing page moderna e humanizada desenvolvida em React, Tailwind CSS e Framer Motion para apresentação de serviços de psicoterapia clínica, atendimentos online e presenciais.

## 🌿 Tecnologias Utilizadas

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Framer Motion** (animações fluidas)
- **Lucide React** (ícones)
- **Canvas Confetti**

## 🚀 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/RaphaCalixto/Psicologa.git
cd Psicologa
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para gerar a build de produção:
```bash
npm run build
```
